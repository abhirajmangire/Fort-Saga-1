# Fort-Saga 🏰

Fort-Saga is a website built for fort enthusiasts and travelers — a single place to explore forts, plan trips around them, stay updated with fort-related information, and share posts and experiences with a community of fellow explorers.

## Features

- 🗺️ **Explore Forts** — Browse and discover forts with details to help plan your visit
- 🧭 **Trip Planning** — Plan trips centered around fort locations
- 📰 **Information Updates** — Stay informed with the latest fort-related news and updates
- 📝 **Post Sharing** — Share your own fort visit experiences, photos, and stories with others
